# DNSRW
按无线网络或移动网络重写系统 DNS - LSPosed

# 支持版本
Android 15+，LSPosed API 102

# 实测机型
努比亚 Z80 Ultra（Android 16，NebulaAIOS2.0.26MR_NX741J）

# 使用说明
1. 安装APK，并在LSPosed中启用模块。
2. 确认模块作用域仅包含“系统框架（`system`）”，并重启手机使模块生效。
3. 在应用中设置无线网络和移动网络的默认`DNS`，也可按网络单独设置重写规则。
